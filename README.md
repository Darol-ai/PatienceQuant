# PatienceQuant · 低频智能量化投资系统

智能证券投资课程项目：面向 A 股的低频量化演示系统。

```text
本地行情库 → 股票池（研究标注、股票池分析）→ 制定策略（因子权重 / 系统内训练模型）
          → 成绩卡与回测报告 → 智能体推荐 → 模拟盘自动调仓 → 交易记录与持仓收益
```

只做回测和模拟盘，不连接券商、不用真钱。港股已调研数据源，未接入；只覆盖 A 股。

**演示请看 [`docs/使用说明.md`](docs/使用说明.md)**：一份约 15 分钟的演示脚本，按作业要求逐项走一遍。

## 快速启动

后端 Python 3.11（conda 环境或 `make setup`），前端 Node 20+：

```bash
make setup
make backend   # http://localhost:8000
make frontend  # http://localhost:5173
```

或 `docker compose up --build`，浏览器打开 http://localhost:8080。

- **数据**：在 `backend/.env` 填 `TUSHARE_TOKEN`（参照 `.env.example`）。日线、指数和历史成分股随仓库通过 Git LFS 分发（需要 git-lfs）；每日指标（估值、换手率、市值，约 500MB）不随仓库分发，第一次启动时从 tushare 补齐（约 4,000 次调用、半小时左右，补齐前估值、换手率、市值类因子没有值）。之后服务启动时自动补齐到最近交易日。详见 [`docs/部署-真实数据准备.md`](docs/部署-真实数据准备.md)。
- **模型**：系统内训练的模型不进仓库。新环境第一次启动时，内置模型策略缺的模型会自动排队训练（每个 1.5～6 分钟），训练完自动计算成绩卡。
- **大模型**（可选）：在"AI 工具"页配置，保存即生效；不配置时智能体只能用按钮提问。

## 系统组成

| 部分 | 说明 |
|---|---|
| 本地行情库 | A 股日线与复权因子、每日指标（估值、换手率、市值），2010 年起；沪深300 指数 2005 年起与历史成分股 2010 年起。系统里行情数据的唯一来源 |
| 股票池 | 沪深300（回测和训练在每个调仓日只用当时的成分股）、30 支候选池、全市场、自定义股票池；自定义股票池可做研究标注（所属板块、研究理由）；股票池分析（板块分布、收益-波动散点、等权组合对沪深300） |
| 因子库 | 价量、动量、风险、形态、估值、换手率、市值、行为金融等，全部只用日线和每日指标；基本面和盈利质量需要财务报表，未接入 |
| 策略流水线 | 打分 → 选股（前 N 名 / 前 x%）→ 权重（等权 / 按分数，单股上限）→ × 择时仓位 → 调仓（只交易差额、换手阈值、按手取整）；回测和模拟盘共用同一套代码 |
| 系统内训练 | LightGBM / XGBoost（GPU）/ LSTM；逐年滚动（给 Y 年打分的模型只用 Y−1 年 6 月底前的样本训练、下半年验证）；训练设置完全相同时复用模型 |
| 择时 | 沪深300 均线趋势、RSRS、QRS、ICU 均线、鳄鱼线、LLT、均线交叉通道突破、单向波动差、RPS 单向波动差、高阶矩、价量共振；每天收盘判断、次日调整仓位 |
| 成绩卡与智能体 | 每个策略在标准条件（2019–2025、100 万、默认股票池、含费用）下的回测；智能体按回撤和调仓偏好在成绩卡里选，只解释、不下单 |
| 模拟盘 | 绑定策略、手动/自动调仓、净值与买卖点、持仓浮盈、交易账本（可解释、可导出） |

部分择时信号和选股因子移植自 [QuantsPlaybook](https://github.com/hugo2046/QuantsPlaybook)（作者同意使用），出处和未移植的原因见 [`NOTICE`](NOTICE)。设计决定记录在课题工作目录的 `docs/adr/`（ADR-0047 ～ 0053，不在本仓库里）。

如实说明这些数字的边界：

- **30 支候选池排第一，不代表它最好**：名单是研究阶段事后挑的，早年回测偏乐观，这一点修不掉。
- **修正幸存者偏差后数字大幅下降**：此前 README 写的"沪深300 策略 7 年复合 +600% 以上"，是用今天的成分股名单回看过去得到的。改用当时真实的历史成分股后，同一个集成策略从年化 29.5% 降到 8.6%（ADR-0052）。
- **训练历史长短是模型好坏的关键**：系统内训练的模型用 2010 年起的数据、按历史成分股训练，略好于旧模型；同样的设置只用 2016 年起的数据，年化只有 3～5%（消融见 ADR-0052）。
- **LSTM 排第二，但原因没有拆开**：它和树模型的区别不只是网络结构，标签（池内排名）和输入（百分位序列）也不同，没有做消融。何况它是二十多个策略里的一个，有挑选的运气成分。
- **择时整体拖累收益**：配在集成模型上的 10 个择时里，只有单向波动差略好于不择时的集成模型（8.6%），其余都更差。
- **历史回测不代表未来收益。**
