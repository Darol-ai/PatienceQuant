# PatienceQuant · 低频智能量化投资系统

智能证券投资课程项目：面向 A 股的低频量化演示系统。

```text
本地行情库 → 股票池（研究标注、股票池分析）→ 制定策略（因子权重 / 系统内训练模型）
          → 成绩卡与回测报告 → 智能体推荐 → 模拟盘自动调仓 → 交易记录与持仓收益
```

只做回测和模拟盘，不连接券商、不用真钱。港股已调研数据源，未接入；只覆盖 A 股。

**演示请看 [`docs/使用说明.md`](docs/使用说明.md)**：一份约 15 分钟的演示脚本，按作业要求逐项走一遍。

## 快速开始（复现与检查）

需要 Linux 或 macOS、Python 3.10 以上（推荐 3.13）、Node 20 以上；训练 LSTM 和 XGBoost 推荐 NVIDIA 显卡（没有也能用 CPU，只是更慢）。

```bash
git clone https://github.com/Darol-ai/PatienceQuant.git && cd PatienceQuant
make setup       # 建虚拟环境，按 backend/requirements-lock.txt 安装依赖（含 GPU 版 torch），安装前端依赖
make data        # 下载数据包（约 1.2GB，GitHub Release 附件）：行情库 2010–2026、每日指标、旧模型文件
make reproduce   # 可选：训练内置模型、计算全部成绩卡，并与 docs/成绩卡快照.json 逐项对比（GPU 约 1 小时）
make backend     # 终端一：后端 http://localhost:8000（接口文档 /docs）
make frontend    # 终端二：前端 http://localhost:5173
```

- **不需要任何密钥就能运行**：数据包里已经有到 2026-09-23 的全部行情。想补到最新交易日，在 `backend/.env` 填 `TUSHARE_TOKEN`（参照 `.env.example`），服务启动时会自动补齐。详见 [`docs/部署-真实数据准备.md`](docs/部署-真实数据准备.md)。
- **模型**：系统内训练的模型不进仓库。第一次启动时，内置模型策略缺的模型会自动排队训练（每个 1.5～6 分钟），训练完自动计算成绩卡；`make reproduce` 会一次性做完并对比。
- **大模型**（可选）：在"AI 工具"页配置，保存即生效；不配置时智能体用按钮提问。
- **测试**：`make test`（后端测试不调用真实大模型；前端类型检查与构建）。

## 系统组成

| 部分 | 说明 |
|---|---|
| 本地行情库 | A 股日线与复权因子、每日指标（估值、换手率、市值），2010 年起；沪深300 指数 2005 年起与历史成分股 2010 年起。系统里行情数据的唯一来源 |
| 股票池 | 沪深300（回测和训练在每个调仓日只用当时的成分股）、30 支候选池、全市场、自定义股票池；自定义股票池可做研究标注（所属板块、研究理由）；股票池分析（板块分布、收益-波动散点、等权组合对沪深300） |
| 因子库 | 价量、动量、风险、形态、估值、换手率、市值、行为金融等，全部只用日线和每日指标；基本面和盈利质量需要财务报表，未接入 |
| 策略流水线 | 打分 → 选股（前 N 名 / 前 x%）→ 权重（等权 / 按分数，单股上限）→ × 择时仓位 → 调仓（只交易差额、换手阈值、按手取整）；回测和模拟盘共用同一套代码 |
| 系统内训练 | LightGBM / XGBoost（GPU）/ LSTM；逐年滚动（给 Y 年打分的模型只用 Y−1 年 6 月底前的样本训练、下半年验证）；训练设置完全相同时复用模型 |
| 择时 | 沪深300 均线趋势、RSRS、QRS、ICU 均线、鳄鱼线、LLT、均线交叉通道突破、单向波动差、RPS 单向波动差、高阶矩、价量共振；每天收盘判断、次日调整仓位 |
| 成绩卡与智能体 | 每个策略在标准条件（2019–2025、100 万、默认股票池、含费用）下的回测；智能体按回撤和调仓偏好在成绩卡里选，只解释、不下单 |
| 模拟盘 | 绑定策略、手动/自动调仓、净值与买卖点、持仓浮盈、交易账本（可解释、可导出） |

部分择时信号和选股因子移植自 [QuantsPlaybook](https://github.com/hugo2046/QuantsPlaybook)（作者同意使用），出处和未移植的原因见 [`NOTICE`](NOTICE)。设计决定与分析过程记录在 [`docs/adr/`](docs/adr/)（54 份），术语见 [`docs/CONTEXT.md`](docs/CONTEXT.md)。

说明：

- **策略参数**：因子与择时策略沿用研报或原作者的默认参数，模型策略使用统一的默认训练设置，都没有做逐个的精细调优。本项目的重点是平台能力——数据、因子、训练、回测、推荐和模拟交易的完整链路，以及结果的可复现与可审计。
- **回测口径**：沪深300 策略在每个调仓日只用当时真实的成分股（历史成分股），避免用今天的名单回看过去带来的幸存者偏差；30 支候选池是研究阶段选定的固定名单。
- **模型训练**：系统内训练的模型用本地行情库 2010 年起的数据逐年滚动训练，给某一年打分的模型只用该年之前已揭晓的样本。训练历史长短对模型效果的影响见 ADR-0052 的消融实验。
- **择时**：择时信号统一配在同一个集成模型上，便于横向比较不同择时方法。
- 历史回测不代表未来收益。

## 开发

```bash
cd backend && ../.venv/bin/python -m pytest -q   # 后端测试（不调用真实大模型、不自动训练）
cd frontend && npx tsc -b                        # 前端类型检查（tsc -p . 不检查任何文件）
```

仓库里有：`backend/`（FastAPI 后端、策略流水线、训练、回测、模拟盘）、`frontend/`（React 前端）、`scripts/fetch_data.py`（下载数据包）、`backend/scripts/reproduce.py`（一键复现）、`docs/`（使用说明与演示脚本、演示轨迹、设计决定、术语表、截图）。
