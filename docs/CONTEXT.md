# 智能证券投资课程项目

本项目为"智能证券投资"课程作业：一个针对沪深 A 股大盘股的**低频量化交易系统**，需能演示自有策略、给出多年回测收益、并通过模拟盘进行自动化交易。本文件只是术语表，不含实现细节。

助教下发的《金融量化交易平台产品需求文档》(仓库内 `.docx`) 是本项目的**愿景文档**：它描述完整形态(多市场、OMS/EMS、高频层、AI 编排、多租户)，本期只实现其中一条**纵切**并对齐 §19.1 的基本功能验收。选型理由见 `docs/adr/`。

## 市场与标的

**A 股**：
在上海证券交易所、深圳证券交易所上市的人民币普通股。本项目的市场范围之一（另一个是 [[港股]]）。
_Avoid_: 股市、大陆股票

**港股**：
在香港交易所上市的股票。**本期不接入**：已调研数据源，系统只覆盖 [[A 股]]（ADR-0053）。以后接入时只考虑港股通标的（内地投资者可通过港股通买卖的那部分）。
_Avoid_: 香港股市

**沪深300**：
沪深两市规模最大、流动性最好的 300 只股票构成的指数，本项目"大盘股"股票池的默认基准与选股域。
_Avoid_: HS300、大盘

**股票池**：
一组有名字的股票，每次[[策略实践]]时选一个作为策略的选股范围。分两种：系统提供的固定股票池（如沪深300 成分股、30 支跨行业候选池）和用户自定义的股票池。股票池不属于策略本身；策略只记一个"默认股票池"，回测时可以换。作业原文写作"池塘"，以本词为准。
_Avoid_: 池塘、自选股、watchlist（英文可用 stock pool）

**研究标注**：
用户给自定义[[股票池]]里每只股票写的"所属板块/主题"和"研究理由"。作业要求每组把研究的股票和板块标注清楚（至少十只），以本词为准。标注属于股票池，不属于策略。
_Avoid_: 备注、标签

**股票池分析**：
对一个[[股票池]]本身的图表分析：行业/板块分布、成员近一年收益与波动、股票池等权组合对沪深300 的走势。作业原文"池塘分析"即指此。它分析的是选股范围，不是策略的表现。
_Avoid_: 池塘分析

**历史成分股**：
某个指数在过去某一天真实包含的股票名单。以指数命名的[[股票池]]（如沪深300 成分股）在回测和训练的每个时点只用当时的历史成分股，不用今天的名单——用今天的名单回看过去，等于事先知道哪些股票后来表现好（幸存者偏差）。
_Avoid_: 最新成分股（只适用于"今天"）

**复权**：
对历史价格按分红送配进行调整，使价格序列可比。回测一律使用**前复权**日线。
_Avoid_: 除权处理

## 策略

**策略**：
一套明确、可执行、可回测的规则，规定何时买卖哪只股票、买卖多少。完整策略 = 选股 + 择时 + 仓位/风控 + 交易执行四部分，任何一条不得含模糊人工判断。每个策略只属于一个市场（[[A 股]]或[[港股]]），不跨市场混合持仓。按选股依据分两类：
- **因子权重策略**：人工给各组[[因子]]设定权重，加总成综合分选股；不涉及训练。
- **模型选股策略**：用某个[[模型]]的打分选股；模型的参数由训练产生，不能手工改。
_Avoid_: 打法、玩法、算法（"算法"在日常说法里常指模型，本项目不用它指策略）

**模型**：
可训练的预测器（如 LightGBM、XGBoost、Transformer、LSTM）：输入一组[[因子]]，输出对股票的打分（预测未来一段时间的收益）。模型在[[策略制定]]时由某个模型选股策略训练产生，归该策略所有；输入因子、算法、预测周期、训练股票池、超参数只要有一项不同，就是另一个模型，需要重新训练。只有这些都相同时（例如"基于它新建"只改了选股、权重、择时或调仓），系统才让新策略沿用已有模型。用户不直接挑选模型。
_Avoid_: 算法、AI

**模型库**：
所有已训练模型的登记处：每个模型的输入因子、算法、预测周期、训练股票池、逐年样本外成绩，以及归属的策略。只用来浏览和追溯，不是挑选模型的地方。模型只能通过系统内的训练功能产生（采用固定的滚动训练方式），或作为**旧模型**导入——旧模型指此前离线流程训练出的模型，保留原样以便已有成绩可复现。
_Avoid_: 算法仓库、算法库

**打分**：
策略对股票池里每支股票在某一天给出的一个分数，分数越高越优先买入。由[[因子]]按人工权重加总（因子权重策略），或由[[模型]]算出（模型选股策略）。后续的选股和仓位只看分数，不关心它是怎么来的。
_Avoid_: 信号（"信号"专指[[择时信号]]和[[LightGBM 信号]]）

**择时信号**：
对整个市场（通常是一个指数）给出的"现在该持有多少股票"的比例，0% 到 100%。决定买多少，不决定买哪些。
_Avoid_: 大盘判断、仓位信号

**本地行情库**：
存在本地、随仓库一起分发的历史行情数据（K 线、复权、指数、成分股），是系统中行情数据的唯一来源：看板、股票池、回测、模型训练和模型运行都只读它。启动时发现它落后于最近交易日就自动补齐，运行中也可以手动触发补齐；数据源只在补齐时才被调用。策略定义、回测记录、模拟盘账户、模型库登记这些业务数据不属于它，另行保存。
_Avoid_: 缓存（缓存可以随时丢弃重建，本地行情库是随仓库发布的正式数据）

**策略库**：
所有可供回测、可被智能体推荐的[[策略]]的集合。每个策略的每一次回测结果都保留，可随时调出查看。

**策略制定**：
定义一个策略并存进[[策略库]]：市场、[[打分]]方式、[[择时信号]]、选股规则、权重方案、调仓频率。因子权重策略在这里从[[因子库]]选因子、设权重；模型选股策略在这里选算法、从因子库选输入因子、定预测周期和训练股票池，保存时训练出它的[[模型]]并按标准条件回测得到[[成绩卡]]。由用户填表单完成（[[智能体]]不生成策略）。改其中任何一项都是另存一个新策略。

**策略实践**：
从[[策略库]]选一个策略，设定这次回测的起止日期、初始资金、股票池和费用，运行[[回测]]并查看结果。不改动策略本身。

**成绩卡**：
策略库里每个策略附带的一组事实数据：市场、风格、样本外年化收益、最大回撤、夏普等。智能体推荐策略时引用的数字只能来自成绩卡。
_Avoid_: 策略池（易与[[股票池]]混淆）

**因子**（factor）：
一个在某一天能对每支股票算出一个值、可用来给股票横向排序的指标，如 20 日收益、60 日波动率、上下影线、市盈率。每个因子写明计算方法、方向（越大越好还是越小越好）和所需数据。因子只有一种含义：因子权重策略把若干因子按权重加总成综合分；模型把若干因子当作输入。基本面、估值、盈利质量类因子需要财务数据，没有真实财务数据时不参与打分。
_Avoid_: 特征（机器学习里模型的输入叫特征，本项目统一叫"模型的输入因子"）、指标（"指标"在本项目专指技术指标）

**因子组**：
一组同类因子（如动量组 = 3/6/12 个月收益），组分数是组内各因子分数的平均，方便因子权重策略一次选一组。

**因子库**：
系统里全部因子的唯一目录。策略库里任何策略用到的因子都必须先登记在因子库里；因子由开发随策略库扩充加入（写成带测试的代码），用户不能自行添加公式。
_Avoid_: 特征库

**智能体**（agent）：
以对话方式询问用户的偏好（市场、能接受的最大回撤、持仓周期），按固定规则在[[策略库]]里推荐**单个**[[策略]]，并解释推荐理由的助手。选哪个策略由规则决定，大模型只负责理解提问和解释；解释里引用的数字只能来自[[成绩卡]]。智能体不下单、不修改策略。每次推荐都留下[[审计留痕]]。
_Avoid_: AI 交易、机器人投顾

**AI 助手**（ai-assistant）：
除[[智能体]]之外由大模型提供的辅助工具，如研报总结、从研报生成因子、解释某一笔真实交易。只做解读和生成候选，不直接改动策略或下单。每次调用都留下[[审计留痕]]。
_Avoid_: AI 交易

**作业三分法（模型 / 文字 / 综合策略）映射**：
- **模型策略** = [[策略]]里的"模型选股策略"（用训练过的[[模型]]打分选股，如沪深300 集成策略）。
- **文字策略** = 本项目不做。
- **综合策略** = 同时使用[[模型]]打分和[[择时信号]]的策略（如"集成模型 + RSRS 择时"）。

## 系统

**回测**（backtest）：
在历史数据上模拟执行策略、计算收益与风险指标（年化收益、夏普比率、最大回撤），需处理 A 股特有约束：涨跌停、T+1、停牌、退市、财报披露滞后、印花税与冲击成本。
_Avoid_: 历史验证、复盘

**模拟盘**（paper trading）：
用实时或回放行情、虚拟资金按策略自动下单的账户，由本地模拟撮合成交，不产生真实成交。作业要求的演示形态，本期即以此充当验收里的"实盘"环节。
_Avoid_: 仿真盘、纸上交易

**实盘**：
接入券商、用真实资金下单。作业不要求，本期仅保留券商适配器接口桩（如 [[miniQMT]]）。
_Avoid_: 实战盘

**数据快照**（data snapshot）：
一份不可变、带版本号的确定数据集合。回测任务必须绑定某个数据快照 ID，配合固定随机种子，保证同版本回测结果可复现。
_Avoid_: 数据版本（指快照的编号，不指快照本身）

**审计留痕**：
对每次 [[AI 助手]] 调用或人工关键操作记录下：模型版本、输入、输出、时间、依据、置信度、是否被采纳、可否回滚。对应验收 §19.1 第 5 条。
_Avoid_: 日志（日志是技术设施，审计留痕是业务要求）

**数据说明**：
每个策略写明它用了哪几年的数据：[[模型]]的训练数据区间（逐年滚动）、预热数据，以及成绩卡的回测区间和[[收益点数]]。作业原文"策略上写清楚综合了哪几年的数据"以本词为准。
_Avoid_: 数据来源（那是行情数据源）

**每日指标**：
每只股票每个交易日的估值与交易指标：市盈率、市净率、市销率、股息率、换手率、总市值和流通市值。与日线一起存进[[本地行情库]]；它让估值类[[因子组]]和换手率、市值类[[因子]]有真实数据。财务报表（ROE、毛利率等）不在其中。
_Avoid_: 基本面数据（基本面指财务报表）

**数据包**：
把本地行情库、每日指标和旧模型文件打成的一个压缩包，作为代码仓库的 Release 附件分发，老师或新环境用它一次得到全部数据。代码仓库本身不含数据。
_Avoid_: 数据集、LFS 文件

**成绩卡快照**：
某一时刻全部内置策略的成绩卡数字，随代码仓库一起提交，用来检查别人复现出的成绩卡是否一致。它是对照基准，不是系统运行时读取的数据。
_Avoid_: 基准结果、缓存

**收益点数**（"赚了多少个点"）：
作业验收口径，指策略在指定回测区间的累计收益百分比（如"赚了 60 个点" = +60%）。报告中同时给出年化收益与最大回撤。

## 外部工具与概念

**行情数据源**：
获取 A 股行情/基本面的渠道——不再是"免费数据源"（tushare 走的是付费/积分制的第三方通道，见下），改名去掉"免费"这个不再准确的限定词。实际落地是 **tushare 1.4.24 为主**（AKShare 在部署环境访问不通，代码保留但未启用；BaoStock 已完全移除，见 [[ADR-0046]]）；取到的行情只写进[[本地行情库]]。tushare 走的是非官方中转（`https://tuaremax.top`，不是官方 `api.waditu.com`）——用户知情且明确要求使用，风险记录在 [[ADR-0046]]。调用统一走连接层（限速/超时/重试），坚持"real 优先、失败可见，不静默退回 demo 数据顶替"，这条原则从 [[ADR-0045]] 延续到 [[ADR-0046]]。

**PatienceQuant**：
一个已跑通的全栈参考项目（FastAPI+SQLAlchemy+React），本项目改造起点，见 [[ADR-0004]]。
不要和它自己内部 `StrategyConfig.name` 默认值里的"V3"混淆——那是它自己的版本号，
和本项目的 V3 策略方案是两回事。
_Avoid_: vnpy、Qlib（技术选型已改用 PatienceQuant 现成的引擎，见 [[ADR-0004]]，不再单独引入）

**miniQMT**：
券商（讯投 QMT 体系）提供的官方轻量级 Python 量化接口，通过 `xtquant` 库连接极简客户端实现程序化下单。本期不接入，仅作为[[实盘]]适配器接口桩的参照。
_Avoid_: 小QMT

## 历史方案（已停用）

以下术语属于此前的 V3 方案（《选股与LightGBM模拟交易方案_V3.md》，"规则选股、LightGBM 产生入场与退出信号、账户程序模拟执行"）。对应代码已在 ADR-0048 删除，新功能和页面不再使用这些说法，保留在这里只为读懂旧 ADR 和旧报告。

**配置组**：
红利 / 成长 / 周期三组，按行业范围划分，各自有独立的资格条件、因子评分公式（S_D/S_G/S_C）和预算上限（40%/30%/30%）。LightGBM 训练时三组合并、配置组作为分类特征。
_Avoid_: 板块（板块指具体行业，配置组是更高一层的分类）

**预候选池**：
每季度末按市值在每个配置组内取前 30 只（需先满足上市年限、市值、ST 等基础资格），三组合计最多 90 只，是季度因子打分和月度权重重算的范围。
_Avoid_: 股票池（[[股票池]] 是更泛的通用词，预候选池专指这个季度重建的候选集合）

**LightGBM 信号**：
`LGBMClassifier` 三分类模型，输出 `p_up`/`p_down`/`p_neutral`——未来 20 个交易日内先触及标签上边界、先触及下边界、或两者都未触及的估计概率。分 **L1**（波动率缩放边界，主标签）和 **L0**（固定 +8%/−5% 边界，对照）两个标签版本。决策一律用**校准后**的概率，不用原始概率。
_Avoid_: 预测收益率、交易胜率（p_up 不是"会涨"或"会赚钱"的概率，只是"是否先触及某价格边界"的概率）

**收益预测分数**：
回归模型对一只股票未来一段时间收益的预测值，只用来在同一天的股票池内排序、取前若干名，不当作收益承诺。沪深300 集成策略的分数 = LightGBM 与 XGBoost 两个独立训练的模型分数取平均。与 [[LightGBM 信号]] 是两回事：后者输出三分类概率，前者输出一个连续的收益估计。
_Avoid_: 预测收益率（容易被读成"能赚多少"）

**建仓基准价 B / 区间最高价 H**：
B 是本轮持仓第一次实际建仓价；H 是本轮持有期内的最高有效收盘价，初始化不低于 B。用于固定止损（`Q/B-1<=-15%`）和跟踪止损（`Q/H-1<=-10%` 且曾涨过 25%+）。部分加减仓不重置 B、H。

**退出类型**：
本项目区分五种互斥的退出原因，优先级为 资格退出/固定止损/跟踪止损 > 模型风险退出 > 普通减仓：**资格退出**（换出预候选池或月末资格失败）、**固定风险退出**（价格止损 -15%）、**跟踪风险退出**（追踪止损）、**模型风险退出**（连续两日 `p_down>=0.65`）、**模型主动止盈**（连续两日 `Q/B-1>=10%` 且 `p_down>=0.50` 且 `p_up<=0.35`）。
_Avoid_: 止损（止损只指固定风险退出一种）

**冷静期**：
主动清仓后 20 个完整交易日内禁止对该股票新增买入，期满后等下一个月末才重新纳入判断。

**A 阶段 / B 阶段**：
交付分两阶段。**A 阶段**（`fixed_pool_demo`）用方案里固定的 10 只研究股票跑通信号/订单/账本全链路，本期冲刺只做这个。**B 阶段**（`dynamic_pool_research`）是完整的季度动态选股，需要十年历史财务/分红/公司行动数据验收，属于后续阶段，不在本期范围内。

**qualification_mode**：
A 阶段的两种子模式。`verified` = 10 只股票的历史资格已核验，可跑真实因子排名；`engineering_only` = 未核验历史资格，只做固定预算、等权信号演示，仅验证账本工程是否正确，不代表策略实际表现。

**影子单笔诊断**：
对月末候选名单里每个信号单独开一个不占用主账户资金、不生成主账户订单的模拟买卖，用于检验"标签触发"和"单笔能否真的赚钱"是否一致。与主账户回测是两件独立的事，不能互相替代。

**账户版本 A/B/C/D**：
