# 部署前必读：真实数据怎么来

## 需要配置的密钥

在 `backend/.env` 里填上 tushare 的 token（参照 `.env.example`）：

```
TUSHARE_TOKEN=你的token
TUSHARE_HTTP_URL=https://tuaremax.top
```

`.env` 不会被提交到仓库。用 Docker 部署时，同名环境变量会通过 `docker-compose.yml` 传进容器。

## 策略依赖的数据和模型

三个沪深300策略（LightGBM / XGBoost / 集成）和30支候选池策略，依赖 `backend/data/` 下一批历史数据和训练好的模型文件。它们通过 **Git LFS** 跟仓库一起分发：本机装好 `git-lfs` 后正常 `git clone` 就会带上，不需要任何额外准备。

| 文件/目录 | 用途 |
|---|---|
| `csi300_constituents.parquet` | 沪深300 成分股名单 |
| `csi300_universe_history.parquet` | 沪深300 成分股历史行情（2010 年起） |
| `real_csi300_index.parquet` | 沪深300 指数点位（回测超额收益对照） |
| `csi300_lightgbm_ensemble_model_walkforward/` | LightGBM 沪深300 策略的模型（按年、按随机种子分目录） |
| `csi300_xgboost_ensemble_model_walkforward/` | XGBoost 沪深300 策略的模型 |
| `broad_universe_history_extended.parquet` | 30 支候选池历史行情（2010 年起） |
| `broad_regression_h90_ensemble_model_walkforward/` | 30 支候选池策略的模型 |

万一这批文件缺失（比如浅克隆没带 LFS），系统启动时会检测到并跳过注册相关策略，其它功能照常可用。

## 这批文件怎么更新

这批文件由此前的离线脚本流程生成。按 ADR-0047，离线脚本已经停用并从仓库删除（Git 历史里可以找回）。之后的做法是：

- **行情数据**并入本地行情库：服务启动时自动补齐到最近交易日，运行中也可以手动补齐。
- **模型**只能通过系统内的训练功能产生，训练结果登记进模型库。现有模型作为"旧模型"原样保留，已有回测成绩可以复现。

这两部分正在开发中。在它们完成之前，这批文件保持现状，不会被更新。

## 交给 Docker 部署

`docker-compose.yml` 把 `backend` 的数据目录绑定到宿主机：

```yaml
volumes:
  - ./backend/data:/app/data
```

只要文件在 `PatienceQuant/backend/data/` 下，`docker compose up` 启动的容器就能直接用。

## OpenAI Key 不需要重启

`OPENAI_API_KEY` / `OPENAI_BASE_URL` / `OPENAI_MODEL` 可以直接在前端"AI 投研"页面右上角"API 设置"里配置，保存后立即生效。`.env` 里的值作为没在前端配置过时的默认值保留。
