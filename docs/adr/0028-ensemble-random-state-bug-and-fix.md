# 模型集成：先撞上一个真实bug，修复后是本轮最大幅度的净正改善

## 动机

ADR-0027 排除了模型容量不足的假设后，剩下的未测方向之一是模型集成——
多个不同随机种子训练、平均预测，降低单模型对训练噪声的敏感度，对所有
年份统一应用，不是只为2019定制。

## 第一次尝试撞上的真实bug：random_state 没有任何效果

第一版实现（5个种子，其余超参数不变，只改 `random_state`）跑出来的
结果和不集成的单模型**逐年数字完全相同**（连浮点数都基本一致）。
排查发现：LightGBM 默认不做行/列子采样（`subsample`/`colsample_bytree`
都是1.0），贪心分裂在同样数据、同样超参数下是完全确定性的——
`random_state` 只控制采样过程的随机数生成器，**没有采样就没有随机性
可控制**，5个"不同种子"的模型其实是同一棵树训了5遍，逐一验证过5个
模型文件的md5哈希互不相同（说明训练确实各跑了一次），但预测输出
逐位相同，证实了这一点。

如实记录这个过程：**先撞上bug，通过"结果不该这么精确重合"这个矛盾
发现问题，修好后重新测试**——和 ADR-0019 发现基准计算bug是同一种
方法论（对好看/异常的结果保持怀疑）。

## 修复

`subsample=0.8, subsample_freq=1, colsample_bytree=0.8`——显式打开行/列
子采样，不同 `random_state` 才会真正采到不同的子样本/子特征集，训出
结构不同的树。修复后验证：同一天同一支股票，5个模型的预测值明显不同
（0.145~0.174区间），不再是bug状态下的完全一致。

新增 `app/quant_v3/ensemble_regression_signal.py`
（`EnsembleRegressionSignalSource`/`EnsembleRegressionWalkForwardSignalSource`，
每年一组5个模型，简单平均预测）+ `scripts/
train_broad_regression_h90_ensemble_walkforward.py`。测试172/172全绿
（复用已有组件的新数据管线，未新增单测，同已有信号源类的先例）。

## 结果：几乎全面改善

| 年份 | 修复前(ADR-0025单模型) | 修复后(5模型集成) |
|---|---|---|
| 2019 | -14.8% | **-11.4%（改善）** |
| 2020 | +11.4% | +13.8%（改善） |
| 2021 | +3.3% | +3.9%（改善） |
| 2022 | +6.0% | +3.5%（略降） |
| 2023 | +10.4% | +10.4%（持平） |
| 2024 | +0.7% | +3.2%（改善） |
| 2025 | +7.7% | +8.7%（改善） |
| 跑赢年数 | 6/7 | 6/7（持平） |
| 7年复合收益 | +406.0% | **+428.0%** |

除2022小幅下降外**几乎所有年份都有改善**，这是本轮系列实验里少见的
"几乎无代价的全面提升"，符合集成方法降噪的理论预期（不是针对某一年
定制的机制，是对所有年份统一生效的通用改进）。已更新为
`scripts/run_broad_regression_per_year_backtest.py` 默认配置。

## 结论

当前最佳配置：30支候选池+扩展历史(2010起)+horizon=90+top_k_ratio=0.4+
5模型集成(subsample/colsample=0.8)+动量兜底(count=2, boost=1.5)+等权重+
无趋势过滤。**6/7年跑赢基准，7年复合收益+428.0%（基准+303.9%）**。
2019累计差距从最初的-21.7%（ADR-0021）收窄到-11.4%（本篇），八轮
独立机制/假设尝试里，模型集成是继动量兜底、权重倍数之后第三个带来
真实净正改善的方向。
