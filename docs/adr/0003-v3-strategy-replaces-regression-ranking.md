# 自有策略改用 V3 方案（三分类信号 + 逐股票状态机），废弃回归排序设计

## 背景

此前 grilling 定的策略方向是：Alpha158 因子 + LightGBM **回归**预测未来收益 → 按分数排序选
top-N → 月度等权调仓 → 均线择时控总仓（已落地为 [[quant.selection.select_target_weights]] /
[[quant.timing.apply_timing_overlay]] 两个纯函数，5 条测试全绿）。

小组独立产出了《选股与LightGBM模拟交易方案_V3.md》，经审阅（数学与权重核对无误，仅一处文档
内部遗留矛盾）后，用户确认：**V3 取代此前的策略方向**。

## 决定

自有策略以 V3 为准：三组（红利/成长/周期）规则因子评分选股 + `LGBMClassifier` **三分类**
（是否先触及波动率缩放的价格上/下边界）产生逐日入场/退出信号 + 每只股票独立维护建仓基准价
B、区间最高价 H、持有天数、两日确认计数器、20 日冷静期的状态机，五种互斥退出原因见
`CONTEXT.md`。本期冲刺只做 V3 的 **A 阶段**（固定 10 只股票，`engineering_only` 起步），
V3 的 B 阶段（季度动态选股、十年历史数据验收）明确排到后续阶段。

## 影响

- `quant.selection`/`quant.timing` 这两个已测试的模块**作废**：V3 的调仓不是"每期重选
  top-N"，是逐日、逐股票的独立状态机，两个纯函数覆盖不了这套逻辑。暂不删除文件，等新模块
  落地后再清理，避免中途丢测试基线。
- `vnpy.alpha` 的 `LgbModel` 目前样例都是回归任务，能否直接套 3 分类还是需要另写训练脚本，
  留作实现阶段的开放问题，不影响本决定。
- Qlib/vnpy 的技术栈选型（[[ADR-0001]]、[[ADR-0002]]）不受影响，变的只是策略逻辑本身。

## 理由

这是小组自己的研究成果，业务上比通用的回归排序更具体、更贴近"能讲清楚为什么赚了多少个
点"的验收要求（每笔退出都有明确、可审计的原因）。复杂度换来的是可解释性和可诊断性，在
2–3 天冲刺里只取 A 阶段以控制范围。
