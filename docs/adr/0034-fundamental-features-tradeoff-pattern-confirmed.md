# 加基本面特征(换手率均值+估值分位)——2019改善但2020/2021转负，同一模式第四次出现

## 动机

ADR-0012 在12支候选池、旧的三分类/等权重机制下测过换手率均值/估值分位
这两个特征，结论是没有增量信息。当前上下文已经完全不同（30支候选池、
回归目标、5模型集成、动量兜底），值得用最终框架重新验证。新抓了30支
股票2010年起的pbMRQ（`scripts/fetch_broad_universe_valuation_extended.py`
→ `data/broad_universe_valuation_extended.parquet`），复用
`enriched_dataset.py` 的16项特征组装训练集，训练5模型集成。

## 结果：2019真的改善了，但代价是2020/2021转负

| | 原始14特征(ADR-0028/0030最终基线) | +换手率/估值(16特征) |
|---|---|---|
| 跑赢年数 | 6/7 | 4/7 |
| 7年复合收益 | +428.0% | +278.4%（更差） |
| 2019超额 | -11.4% | **-7.7%（目前唯一无副作用达成的最佳2019结果）** |
| 2020超额 | +13.8% | **-3.1%（转负）** |
| 2021超额 | +3.9% | **-5.8%（转负）** |

2019确实是历次尝试里改善幅度较大的一次，但2020/2021双双转负，整体
从6/7降到4/7，总收益也更差。

## 重要发现：这是同一种权衡模式第四次出现

| 轮次 | 机制改动 | 2019变化 | 受损年份 |
|---|---|---|---|
| ADR-0023 | 拉长动量窗口 | 改善 | 2020/2024/2025 |
| ADR-0024 | 持仓粘性 | 改善 | 2024 |
| ADR-0032 | 杠杆放大仓位 | 基本不变/轻微恶化 | 2021 |
| ADR-0034(本篇) | 加基本面特征 | 改善 | 2020/2021 |

四次完全不同类型的机制改动（时间窗口、持仓规则、仓位杠杆、特征工程），
都呈现"帮2019就伤2020/2021左右"这个一致的权衡模式。**这不太可能是
巧合，更可能反映一个真实的结构性事实**：2019年和2020/2021年这批股票
的驱动因素方向不同（2019更像普涨式贝塔行情，2020/2021可能更依赖个股
分化的阿尔法），任何让模型/规则更贴近2019那种行情特征的调整，都会
系统性地削弱对2020/2021这类行情的适配度——两者在方法论上有一定的
互斥性，鱼与熊掌不可兼得。

## 结论

不采用基本面特征（维持原始14项价量特征）。这个反复出现的权衡模式
本身是本轮探索里除"2019是结构性难题"之外最重要的方法论发现——它
说明继续寻找"只帮2019、不伤别处"的单一改动，可能从一开始就是在找一个
不存在的解，除非引入某种能够区分"现在是哪种行情"的更根本的机制（但
ADR-0018/0020/0031已经两次证明"检测行情再切换"这条路本身也不成立）。

**最终配置维持不变**：30支候选池+扩展历史+horizon=90(5模型集成)+
top_k_ratio=0.4+动量兜底(count=2,boost=1.5)+等权重+原始14特征。6/7年
跑赢基准，7年复合收益+428.0%（真实基准+303.9%）。测试174/174全绿。
