# 重大bug修复：基准收益计算一直是错的——之前多个"跑赢基准"的结论需要修正

## 发现过程

诊断2019年问题时，查了模型对广度的月度判断，发现模型全年都正确识别出
2019是普涨、广度机制全年都在触发全覆盖（30支股票equal weight全买），
但即便这样策略收益(42.6%)仍然远低于报告的"基准收益"(84.0%)——理论上
"全覆盖等权重"应该非常接近等权重基准本身，不该有41个百分点的差距。
这个矛盾指向基准计算本身有问题，不是策略的问题。

## Bug 本体

`app/quant_v3/a_phase_data_service.py::APhaseDataService.benchmark()`
一直是这样算的：

```python
wide = frame.pivot_table(index="trade_date", columns="symbol", values="close")
mean_index = wide.ffill().mean(axis=1)   # 直接对收盘价取算术平均
```

这是把不同股票的**收盘价原始数值**直接取平均，不是"每支股票投入等量
资金买入持有"的真实等权重基准。价格量级差异越大，扭曲越严重——30支
候选池里贵州茅台(600519.SH)2019年初收盘价约¥500，其余多数在¥2~30，
相差近200倍；官方10支池差距较小但也有约25倍（¥3.2~¥78.8）。价格越高
的股票在这个"均值"里的权重越大，和它实际该有的等资金权重毫无关系。

单测（`tests/quant_v3/test_a_phase_data_service.py`）复现了一个最小
例子：A从100涨到200(+100%)，B从1000跌到500(-50%)，真实等权重(等资金)
收益应该是 (100%-50%)/2=**+25%**，但原实现算出**-36.4%**——不仅数值
错，连方向都反了。

## 修复

```python
normalized = wide / wide.bfill().iloc[0]   # 每支股票先按区间起始价格归一化
mean_index = normalized.mean(axis=1)        # 再取均值——这才是等资金买入持有
```

修复后单测通过，全量回归测试165/165全绿。

## 影响范围：几乎所有涉及基准对比的历史结论都需要重新核实

这个函数是 `PatienceQuant/backend/app/quant_v3/` 全部回测脚本共用的
数据服务，`docs/adr/0001` 到 `0018` 里几乎每一个"跑赢/跑输基准"的具体
百分比数字，都是拿这个错误基准算出来的。已经重新核实的三处：

**官方V3策略（对应ADR-0009，10支股票，价格量级差异较小约25倍）**：
定性结论**没有变**——仍然是 0/7 年跑赢，但每年具体数字都变了（比如
2023年基准从原来报告的-21.7%变成+42.3%，2025年从+143.4%变成+63.8%）。
这是最不受影响的一组结论，因为10支官方股票池价格量级差异相对较小。

**分散化12支候选池（对应ADR-0011/0012，含贵州茅台，价格量级差异约150倍）**：
定性结论**明显改变**——原报告2/7年跑赢(仅2024/2025)，修复后变成
**4/7年跑赢(2021/2022/2023/2025)，2024反而从+12.6%超额翻转成-4.0%
超额**。原本"分散化是主要杠杆"这个方向性判断大概率仍然成立（分散化
带来的风险分散效果是真实的，见最大回撤数据），但具体哪几年跑赢/跑输
的结论需要以这次修复后的数字为准。

**当前最佳配置（对应ADR-0016/0018，30支广泛候选池，含贵州茅台，价格
量级差异约200倍，受影响最严重）**：

| | 原报告(基准计算有bug) | 修复后(真实等权重基准) |
|---|---|---|
| 跑赢年数 | 5/7 | **4/7** |
| 7年策略复合收益 | +289.2%（不变，策略本身没改） | +289.2% |
| 7年基准复合收益 | +239.5% | **+303.9%（真实基准比之前认为的高）** |
| 策略 vs 基准 | "反超"基准 | **策略仍落后基准约15个百分点** |

**ADR-0015/0016 里"7年复合收益首次反超基准"这个此前被当作重要里程碑
的结论是错的**——真实基准比错误计算出来的基准更高，策略实际上从来
没有在总收益上反超过基准。必须如实撤回这个结论，不能因为已经写进
好几篇 ADR 就含糊带过。

## 为什么之前没发现

这个bug从 `APhaseDataService` 最早写出来（服务官方10支股票池）就存在，
当时注释写的是"只用于图表对比，不参与策略计算"——最初的使用场景里
价格量级差异较小(25倍)，扭曲程度不足以让人怀疑，而且早期几轮实验
（ADR-0001-0010）的核心结论本来就是"策略跑输基准"，一个方向性错误的
基准恰好没有把"跑输"看错成"跑赈"，所以没有触发怀疑。等到 ADR-0011
引入贵州茅台这类价格量级差异极端的股票、且策略开始出现"跑赢"的结果
时，才因为一个违反直觉的矛盾（全覆盖等权重不该跟基准差这么多）被
发现。**这是本轮自由探索里最重要的一次诚实修正**：正是因为对
"看起来好的结果"保持怀疑、去交叉验证矛盾之处，才没有把这个bug当成
真实的策略突破continue往下走。

## 当前诚实结论（修复后）

- 当前最佳配置（30支候选池+回归horizon=90+top_k_ratio=0.7+
  breadth_threshold=0.7）：**4/7年跑赢基准，但7年复合收益仍落后真实
  基准约15个百分点（289.2% vs 303.9%）**，没有达到"整个周期收益更高"，
  年度胜率也没有达到"每年都跑赢"。
- 官方V3策略核心结论不变：0/7年跑赢，这批A股大盘蓝筹本身很难被
  这套方法论跑赢。
- 后续任何新实验都要用修复后的 `APhaseDataService.benchmark()`，
  已有的历史百分比数字（ADR-0001-0018里的具体数字）仅供参考方向，
  不能当作精确值引用。
