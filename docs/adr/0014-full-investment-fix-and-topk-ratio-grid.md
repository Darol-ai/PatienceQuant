# 修复"选中一半就只投一半"的现金拖累，网格选定 top_k_ratio

## 发现的问题

ADR-0013 报告了"多数年份跑赢 vs 全周期复合收益仍大幅落后"的矛盾，分析
原因时发现一个结构性设计问题：`RegressionRotationStrategy` 复用了
`allocate_flat_group_budget`（V3 官方"名额空出不顺延"规则），`top_k_ratio
=0.5` 意味着候选池30支只选15支，但预算是按30支均分再只给选中的15支——
**总仓位永远只有50%，另外50%的预算白白空置，不是现金以外的任何形式在
参与市场**。这条规则在 V3 的 engineering_only 范围下是刻意保守的设计，
但用户已经放开限制，没理由继续保留这个"选中一半只投一半"的隐性现金拖累
——尤其是在 2019/2020/2025 这种普涨年份，白白空置一半仓位等于放弃了
一半本该到手的涨幅。

## 修复

新增 `app/quant_v3/budget.py::allocate_full_weight_to_approved`：选中几只
就把预算全投进这几只（`weight = group_budget / len(approved)`），不再按
候选池总数均分。`allocate_flat_group_budget` 保留不动（`V3Strategy` 仍在
用，官方 A 阶段行为不受影响），`RegressionRotationStrategy` 换成新函数。
测试：`tests/quant_v3/test_budget.py`（3个，含一条回归测试确认
`allocate_flat_group_budget` 的"不顺延"规则没被误改）。

## top_k_ratio 网格（改动前定好范围：0.5/0.7/1.0，不看结果反复试）

不设趋势过滤（已在 ADR-0013 验证净效果接近零/轻微负），只测满仓分配下
不同选股比例：

| top_k_ratio | 跑赢年数 | 7年复合收益 | 说明 |
|---|---|---|---|
| 0.5 | 4/7 | +91.2%（vs 基准+239.5%） | 从38.3%大幅提升，但2021转为负超额（满仓放大了当年选股本身的负贡献） |
| **0.7** | **4/7** | **+175.2%**（vs 基准+239.5%） | 目前最好的风险调整后结果 |
| 1.0 | 4/7 | +254.4%（**反超基准+239.5%**） | 见下方诚实说明——这个"反超"不能算数 |

## 重要诚实说明：top_k_ratio=1.0 的"反超"是假象，不能用

`top_k_ratio=1.0` 意味着 `k = round(30*1.0) = 30`，Top-K 选出"全部有打分
的股票"——只要模型能算出分数（几乎每支股票每个月都能），就等于全部
入选，**约等于退化成"月度再平衡的等权买入全部30支"**，LightGBM 的预测
分数在这个配置下基本没有起到筛选作用，只是决定了极少数因数据缺失被
排除的边缘情况。它跑赢基准，是"月度再平衡"本身相对"从头到尾持有不动"
的再平衡溢价（这批股票波动率不低，定期低买高卖有正贡献），跟"模型选股
选得准"没有关系。用户明确要求"以LightGBM模型为主体"，这个配置不满足
这个前提，即使数字最好看也不能当作最终答案——**如实排除，选 top_k_ratio
=0.7**，它保留了真实的"排序淘汰后30%"的选股动作。

同样测过"top_k_ratio=0.7 + 满仓分配 + 趋势过滤"：3/7年跑赢，7年复合
+129.4%——比不加趋势过滤更差，再次确认趋势过滤这个机制在当前设计下是
负贡献，不用。

## 当前最终配置与结果（`scripts/run_broad_regression_per_year_backtest.py`）

30支候选池 + LightGBM回归(20日forward return) + top_k_ratio=0.7 + 满仓
分配到选中股票 + 不设趋势过滤：

| 年份 | 策略 | 基准 | 超额 |
|---|---|---|---|
| 2019 | +36.3% | +84.0% | -47.8% |
| 2020 | +42.7% | +76.5% | -33.8% |
| **2021** | -2.8% | -3.2% | **+0.3%** |
| **2022** | -6.0% | -13.3% | **+7.3%** |
| **2023** | +4.1% | -4.0% | **+8.1%** |
| **2024** | +25.1% | +3.7% | **+21.4%** |
| 2025 | +19.0% | +25.0% | -6.0% |

**4/7年跑赢基准，7年复合收益从修复前的+38.3%提升到+175.2%**（基准
+239.5%）——大幅缩小差距但仍未反超。2024年超额收益+21.4%是目前单年
最好的结果。2019/2020两年依然是最大的拖累（基准当年涨幅本身就
+76%~+84%，任何有筛选/调仓动作的策略都很难追上纯持有不动的涨幅）。

## 下一步

- 2019/2020/2025 这三个"基准暴涨"年份仍然是复合收益落后的主因，
  ADR-0013 提出的"缩短调仓周期、更快跟上强趋势"这个方向还没有验证，
  值得下一轮优先测试。
- `top_k_ratio=0.7` 是网格里三个预设值中最好的一个，但没有做更细的
  网格（比如0.6/0.8），如果要继续微调需要说明这不是过拟合到已见的
  7年数据上——最好在跑下一轮新实验前就把候选值定好。
