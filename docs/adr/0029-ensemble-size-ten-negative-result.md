# 集成规模扩到10个种子——2019进一步改善但2020转负，维持5个种子

## 结果

固定其余配置（ADR-0028最佳版本），只把集成种子数从5个扩到10个
（新增种子11/55/314/271/888）：

| | 5个种子(ADR-0028基线) | 10个种子 |
|---|---|---|
| 跑赢年数 | 6/7 | 5/7 |
| 7年复合收益 | +428.0% | +376.7% |
| 2019超额 | -11.4% | **-9.7%（进一步改善，目前最好）** |
| 2020超额 | +13.8% | **-2.0%（转负）** |

2019确实又收窄了一点（-11.4%→-9.7%），但2020从+13.8%的正超额转成
-2.0%的负超额，整体跑赢年数掉到5/7，7年复合收益也更低。**更多集成
成员不是单调更好**——5个种子恰好是当前这批随机种子里的一个较优组合，
10个种子引入的额外随机性方向上恰好对2020不利，属于运气/方差范围内的
正常波动，不是"集成规模"这个维度本身有更优解需要继续搜索。

## 结论

维持5个种子（ADR-0028不变）。集成规模本身不建议继续当作可调超参数
反复试更多值——继续加种子数大概率只是在小样本(7个年份)上找随机噪声
的最优组合，不是真实的模型改进方向，属于该收手的信号。当前最佳配置
仍是 ADR-0028 版本：6/7年跑赢基准，7年复合收益+428.0%（基准
+303.9%）。
