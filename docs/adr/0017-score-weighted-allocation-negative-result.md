# 按预测分数加权分配——诊断出问题但修复没有生效

## 动机

ADR-0016 诊断 2019 年问题时发现：等权重会把模型真正看好的黑马摊薄成
和其他入选股票一样的权重（002714 牧原股份当年+206%，模型排第7名选中，
但等权重下也只占约1/21≈4.8%仓位）。假设"按预测分数加权，分数越高权重
越大"能让模型的高信心判断发挥更大作用。

## 实现

`app/quant_v3/budget.py::allocate_score_weighted_budget`：入选集合内把
分数平移到非负（减去集合内最小值）再按比例归一化，全部分数相同时退化
成等权重。`RegressionRotationStrategy` 加 `score_weighted` 构造参数
（默认 False，不改变已有行为）。测试：`tests/quant_v3/
test_score_weighted_budget.py`（4个）+ `test_regression_rotation_
strategy.py` 新增1个。测试162/162全绿。

## 结果：整体变差，不是普遍改善

用 ADR-0016 的扩展历史+horizon=90+top_k_ratio=0.7 配置，只把等权重换成
按分数加权：

| 年份 | 等权重超额 | 按分数加权超额 |
|---|---|---|
| 2019 | -43.6% | **-47.9%（更差）** |
| 2020 | -6.4% | **-27.6%（大幅更差）** |
| 2021 | +8.4% | +8.0% |
| 2022 | +7.5% | +3.6% |
| 2023 | +11.7% | **+17.3%（更好）** |
| 2024 | +21.7% | +10.5%（更差） |
| 2025 | -2.0% | -0.2% |
| 7年复合 | **+293.5%** | +210.0%（更差） |

**没有解决2019问题，反而在2020恶化了很多，总体7年复合收益从293.5%
降到210.0%**——如实报告这是一次负结果，不能因为诊断的方向听起来合理
就假装修复生效了。

## 为什么没生效：推测

回归模型预测的原始分数本身是弱信号、噪声较大（这批股票的forward_return
预测本来就没有很强的样本外相关性，前面多个ADR已经反复验证过这一点）。
"分数越高权重越大"这个逻辑隐含假设"分数的相对大小能可靠反映相对信心"，
但如果分数本身在入选集合内部的排序都不够稳定，把权重差距进一步放大
只会放大噪声、放大预测错误的代价——2020年可能正是模型把权重错误地
集中到了后来表现不好的股票上，才会比等权重差这么多。

## 结论

维持等权重（`score_weighted=False`，默认值），当前最佳配置仍是 ADR-0016
的版本（扩展历史+horizon=90+top_k_ratio=0.7+等权重，7年复合+293.5%）。
"按分数加权"这条路径已经测过并证明无效，不再作为当前方案的一部分，
但代码保留（默认关闭）供以后如果模型质量本身提升了（比如样本外IC明显
改善）再重新评估是否值得开启——按权重集中信心这件事，前提是信心本身
要先可靠。
