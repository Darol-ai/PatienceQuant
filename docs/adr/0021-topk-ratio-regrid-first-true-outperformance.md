# top_k_ratio 用真实基准重新网格——首次在修复后的基准上做到5/7年+总收益反超

## 背景

ADR-0019 修复了基准计算bug，ADR-0020 确认广度自适应的"提升"是假象后
撤回。之前选定 `top_k_ratio=0.7`（ADR-0014）是在**错误基准**下选出来
的，策略自身收益不受bug影响，但"该选哪个值"这个决策本身混杂了基准
判断（当时的判断依据之一是"跑赢年数"，直接用了错误基准），需要用真实
基准重新验证这个选择是否依然成立。

## 网格过程（如实记录，包含逐步扩大范围的过程）

固定其余配置（30支候选池、扩展历史、horizon=90、等权重、无趋势过滤、
不加广度机制），先测了 {0.6, 0.7, 0.8}：

| top_k_ratio | 跑赢年数(真实基准) | 7年复合收益 |
|---|---|---|
| 0.6 | 4/7 | +296.3% |
| 0.7（ADR-0014原选定值） | 4/7 | +293.5% |
| 0.8 | 4/7 | +273.6% |

0.6比0.7好，0.7比0.8好，看到这个下降趋势后**往下扩大了搜索范围**（这里
如实说明：这是看到中间结果后临时扩大网格，不是一开始就定好0.3~0.8的
完整范围，存在一定的"看着结果调范围"的风险，但下面会说明为什么最终
结果不是简单的"一直搜到满意为止"）：

| top_k_ratio | 跑赢年数(真实基准) | 7年复合收益 |
|---|---|---|
| 0.3 | 2/7（骤降） | +264.5%（骤降） |
| **0.4** | **5/7** | **+316.5%** |
| 0.5 | 5/7 | +300.6% |
| 0.6 | 4/7 | +296.3% |
| 0.7 | 4/7 | +293.5% |
| 0.8 | 4/7 | +273.6% |

**0.4 两侧都被验证过更差**（0.3骤降到2/7+264.5%，0.5开始往0.7/0.8方向
递减）——这是一个真实的、两侧都有下降验证的局部峰值，不是"扩大范围直到
碰到一个好看的数字就停"。虽然扩大网格范围这个过程本身是看着中间结果
做的决定，但最终选中的点经过了双侧验证，风险比"单向搜索到满意为止"低
很多，如实说明这个过程，让读者自己判断可信度。

## 结果：首次在真实基准下反超

`top_k_ratio=0.4`（组内30支选12支）：

| 年份 | 策略 | 基准 | 超额 |
|---|---|---|---|
| 2019 | +41.8% | +63.5% | -21.7%（仍未解决） |
| **2020** | +72.7% | +64.0% | +8.7% |
| **2021** | +7.1% | -1.9% | +9.0% |
| **2022** | -3.1% | -12.6% | +9.5% |
| **2023** | +11.9% | +8.4% | +3.4%（此前用错误基准算是-7.6%，修复后本来就是赢的） |
| **2024** | +24.3% | +23.3% | +0.9%（险胜） |
| 2025 | +17.9% | +31.4% | -13.5%（仍未解决） |

**5/7年跑赢真实基准，7年复合收益+316.5%，首次真实反超基准+303.9%**
（约13个百分点）。这是本轮自由探索第一次在修复后、可信的基准计算下
做到"多数年份跑赢+总收益也跑赢"。

## 仍未解决

2019（-21.7%）和2025（-13.5%）依然是两个跑输年份，且都是基准本身涨幅
最大的年份（+63.5%/+31.4%）——这印证了本轮系列实验反复出现的结构性
矛盾：候选池越集中（top_k_ratio越小），在个别股票暴涨的普涨年里，"没
选中那部分"的机会成本就越大。0.4这个值本身是"选择性"和"覆盖面"之间
一个还不错的折中，但没有从根本上解决"普涨年跑输"这个问题。

## 结论

当前最佳配置：30支候选池 + 扩展历史(2010起) + horizon=90 + `top_k_ratio
=0.4` + 等权重 + 无趋势过滤 + 不加广度机制。已更新到
`scripts/run_broad_regression_per_year_backtest.py`。距离"每年都跑赢"
还差2019/2025两年，7年总收益已经反超基准。测试165/165全绿（本轮是
参数网格实验，复用已有 `RegressionRotationStrategy`，未新增代码/单测）。
