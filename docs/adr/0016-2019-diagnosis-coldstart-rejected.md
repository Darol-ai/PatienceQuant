# 专项诊断2019年：冷启动假设被证伪，真正原因是近乎普涨行情下的特征选择偏差

## 假设一：训练数据太少（冷启动）——测试后证伪

2019年折的训练样本(11637-12507条，取决于horizon)远少于其他年份（2025年
有5-9万条），怀疑是数据不够导致模型质量差。往前重新抓了全部30支股票
从2010年起的历史（大部分股票能追溯到2010-01-04，`scripts/
fetch_broad_universe_history_extended.py` → `data/
broad_universe_history_extended.parquet`，116843行），2019折训练样本
从12507条涨到50077条（4倍），重训（`scripts/
train_broad_regression_h90_extended_walkforward.py`）后回测：

| | 训练数据2016起 | 训练数据2010起(4倍量) |
|---|---|---|
| 2019策略收益 | +39.6% | +40.4%（几乎没变） |
| 2019超额收益 | -44.4% | -43.6%（几乎没变） |
| 7年复合收益 | +298.8% | +293.5%（几乎没变，甚至略降） |

**训练数据量不是2019表现差的原因**——如实证伪这个假设，不牵强附会说
"稍微好了一点点"就算验证成功。

## 假设二：2019是近乎普涨行情，特征可能带有不利于该年份的偏差

查了2019年30支候选池各股全年收益：**28/30支上涨，只有2支下跌**，
涨幅从-16%到+236%不等，中位数涨幅超过50%。这是一次几乎所有股票齐涨
的行情，任何"筛选掉一部分股票"的机制都天然要冒"筛掉的恰好是涨得最猛
的那批"的风险。

看了2019模型的特征重要性（gain）：`avg_amount_60d`(60日均成交额，
流动性/规模代理指标)最高，其次是`volatility_60d`/`return_120d`/
`max_drawdown_60d`。当年涨幅最猛的两支（立讯精密+236%、牧原股份
+206%）都不是当时最大市值/最高流动性的品种——如果模型学到"避开某类
流动性特征的股票"这类规律，在这类普涨但由中小市值品种领涨的行情里就
会系统性地漏掉最大的涨幅来源。这只是一个基于特征重要性排序的合理推测，
**没有做严格的归因验证**（比如逐月检查模型对这两支股票的预测分数和
实际排名），如实标注为待验证的假设，不是已确认的结论。

## 结论与下一步

- 冷启动假设已证伪，不需要再往这个方向投入（更多历史数据对这个问题
  没有帮助）。
- 2019 大概率是一次结构性难啃的"普涨但由中小盘领涨"的行情，任何做
  减法的选股机制都有天然劣势，可能不是这一版策略特有的缺陷，而是
  "选股"这件事在这类行情里的普遍局限。
- 如果要继续深挖，下一步应该是验证"特征偏差"假设本身：检查2019年
  模型对已实现涨幅最大的几支股票给出的预测分数排名，如果排名确实
  很靠后，才能坐实"特征选择偏差"这个解释；如果排名不算差，说明还有
  别的原因（比如仓位分配/调仓时点问题），需要重新诊断。
- 鉴于已经验证了两个方向（数据量、特征偏差的初步线索）而没有找到一个
  能真正解决2019问题的改动，暂时接受"2019是当前方法论下的已知短板"
  这个诚实结论，转向验证其他能带来更普遍改善的方向，而不是无限期地
  只为了一个历史年份持续调整。
