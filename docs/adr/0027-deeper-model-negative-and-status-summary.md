# 加深模型容量——负结果；2019专项攻坚阶段性总结

## 假设与测试

2019折训练样本已经因为ADR-0016的历史扩展涨到5万+条，比最初的原因
（"样本太少不敢用复杂模型"）已经不成立，假设更深的模型（`num_leaves`
15→63，`max_depth` 4→7，`n_estimators` 300→600，学习率降到0.03配合
早停）能学到更细致的模式，帮助2019这类复杂行情。

## 结果：全面变差

固定其余配置（30支候选池+top_k_ratio=0.4+momentum_override_count=2,
boost=1.5+等权重），只把模型换成更深的版本：

| | 浅层模型(ADR-0025基线) | 深层模型 |
|---|---|---|
| 跑赢年数 | 6/7 | 4/7 |
| 7年复合收益 | +406.0% | +303.3% |
| 2019超额 | -14.8% | -18.3%（更差） |
| 2022超额 | +6.0% | -0.01%（接近打平） |
| 2024超额 | +0.7% | -0.02%（接近打平） |

**没有任何一个维度变好**，如实记录为负结果。原因推测：股票收益预测
的信噪比本身极低，更深的模型更容易拟合训练集里的噪声而不是真实规律，
即便样本量增加到5万+条也不足以支撑这种复杂度——V3方案最初"浅层树
防过拟合"的设计考量，在换成回归目标、扩大候选池之后依然成立，不是
因为数据不够才保守，是这类预测任务本身的信噪比决定的。维持浅层设置
（`num_leaves=15, max_depth=4`）不变。

## 2019专项攻坚：七轮独立尝试的阶段性总结

| 轮次 | 假设 | 结果 |
|---|---|---|
| ADR-0016 | 训练历史太短(冷启动) | 证伪——4倍数据量几乎没变化 |
| ADR-0016(线索) | 模型对流动性特征有偏差 | 未严格验证，只是特征重要性的推测 |
| ADR-0022 | 模型误判个别动量黑马 | **部分有效**——动量兜底机制的起点 |
| ADR-0023 | 动量信号窗口太短，进出流失 | 净负——拉长窗口伤害其他年份 |
| ADR-0024 | 需要持仓粘性避免过早剔除 | 净负——粘性伤害其他年份 |
| ADR-0025 | 黑马权重被稀释 | **净正**——加权重倍数，同时改善两个指标 |
| ADR-0026 | 熊市校准窗口导致误判 | 证伪——更差的校准窗口对应的年份反而跑赢 |
| ADR-0027(本篇) | 模型容量不足 | 证伪——加深模型全面变差 |

七轮里两轮（ADR-0022动量兜底、ADR-0025权重倍数）带来真实、无代价的
改善，把2019的差距从最初的-21.7%（ADR-0021）收窄到-14.8%（ADR-0025），
其余五轮（含本篇）都是负结果或被证伪的假设。**当前配置（ADR-0025版本）
仍是目前为止综合表现最好、且经过最多交叉验证的一版**：6/7年跑赢基准，
7年复合收益+406.0%（基准+303.9%）。

2019 依然是唯一未解决的年份。已经系统性排除了：训练数据量、模型容量、
校准窗口行情特征、持仓粘性/窗口长度这几大类常见的"模型不好用"的原因。
剩下还没测过的方向包括：模型集成（多个随机种子/超参数平均预测降噪）、
更换预测目标本身（比如分类而非回归，或预测排名而非绝对收益），但这些
都是更大的架构改动，边际成本和此前几轮的教训（"改一个地方大概率牺牲
别的地方"）都提示继续深挖单一年份的性价比在下降。
