# 回归目标窗口网格：horizon=90 首次让7年复合收益反超基准

## 动机

ADR-0014 修完"50%现金拖累"的bug后，top_k_ratio=0.7 配置把7年复合收益
从+38.3%提升到+175.2%，但仍落后基准+239.5%，2019/2020/2025 这三个
基准暴涨年份仍是主要拖累。回归目标当时固定用20日forward return，这个
窗口和月度调仓（21个交易日左右）大致匹配，但"20日"这个数字本身没有
特别的道理，只是沿用了 V3 原文标签设计里的20日窗口——现在标签已经换成
回归，没有理由必须锁定20天，值得单独网格测一下。

## 网格（20/60/90/120，逐步扩大范围，130后停止）

固定其余一切不变（30支候选池、top_k_ratio=0.7、满仓分配、不设趋势过滤、
月度调仓），只改回归目标的 horizon：

| horizon(交易日) | 跑赢年数 | 7年复合收益 |
|---|---|---|
| 20（ADR-0014基线） | 4/7 | +175.2% |
| 60（约一季度） | 4/7 | +210.8% |
| **90（约一季度半）** | **4/7** | **+298.8%（反超基准+239.5%）** |
| 120（约半年） | 4/7 | +236.5%（比90差，比基准略低） |

90附近是一个真实的局部峰值——120比90明显更差，不是"horizon越长越好"
的单调关系，说明这不是恰好停在网格末端凑出来的数字。

## 首次反超：+298.8% vs 基准+239.5%

用 `scripts/build_broad_regression_h90_training_dataset.py`/
`train_broad_regression_h90_walkforward.py`/
`run_broad_regression_per_year_backtest.py`（`MODEL_DIR` 常量已切到
h90）复现：

| 年份 | 策略 | 基准 | 超额 |
|---|---|---|---|
| 2019 | +39.6% | +84.0% | -44.4% |
| 2020 | +70.4% | +76.5% | -6.1%（大幅缩小差距） |
| 2021 | +4.4% | -3.2% | +7.5% |
| 2022 | -6.1% | -13.3% | +7.2% |
| 2023 | +5.9% | -4.0% | +9.9% |
| **2024** | **+30.8%** | +3.7% | **+27.1%** |
| 2025 | +23.5% | +25.0% | -1.5%（几乎追平） |

4/7年跑赢基准，且2020/2025两个此前最大的拖累年份差距都大幅收窄，2024年
超额收益达到本轮系列实验最高的+27.1%。测试157/157全绿（这轮全是复用
已有 `regression_dataset.py`/`regression_model_training.py`/
`regression_signal.py` 的新数据管线脚本，代码本身没有改动，不需要新
单测）。

## 必须诚实说明的方法论局限

**horizon 的选择本身是在同一个7年历史窗口上网格搜出来的**——虽然每一年
的模型都是真正的 walk-forward（训练时看不到当年及未来数据，没有跨年
泄漏），但"90天比20/60/120天都好"这个判断，是把全部7年的回测结果摆在
一起比较后选出来的，某种程度上是在用这整个历史区间给 horizon 调参。
如果换一个不同的历史区间（比如往前再取7年，或者往后滚动到2026年之后
的新数据），90 是不是仍然最优不能保证。这和 ADR-0008/0014 里反复强调
的"不能拿回测结果反推参数"是同一类风险，只是这次的参数是模型训练目标
（horizon）而不是策略执行参数（止损/top_k）——本质上一样需要警惕。
如实记录这个局限，不代表结果无效，但读者/评审应该知道这一层不确定性，
不能把"90最优"当成一个稳定不变的事实。

## 下一步

- 2019 仍然是最大的单一拖累（-44.4%），这一年策略几乎全年跑不赢任何
  配置——如果要继续缩小差距，值得单独研究2019年的数据/模型输出，看
  是模型判断错了方向还是仓位不够，而不是继续在全局超参数上搜索。
- 如果条件允许，用更长的历史（比如往前扩展到2010年附近，如果数据源
  支持）重新做一次同样的 horizon 网格，检验"90天最优"是否在不同历史
  区间上稳健，这是回应上面"方法论局限"最直接的办法。
