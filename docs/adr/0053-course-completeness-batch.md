# ADR-0053 对照作业要求补齐：数据说明、股票池分析与标注、每日指标、可复现的内置模型、LSTM

状态：已采纳（2026-09-24）

## 背景

ADR-0052 三步完成后，对照《课题作业要求》逐条检查，仍有缺口：策略没有写明"综合了哪几年的数据"；"池塘分析"只有成员表格没有分析；研究股票和板块无法标注；估值、换手率、市值类因子没有数据；系统内训练的内置模型策略只存在本机；第二批算法未做。用户明确当前目标是系统完整，不是回测表现。

## 决定

1. **数据说明**：策略详情和回测报告顶部写明训练数据区间（逐年滚动规则）、预热数据、回测区间、收益点数与同期沪深300。
2. **股票池分析**：股票池页增加行业/板块分布、成员近一年收益-波动散点、股票池等权组合对沪深300 走势，只用本地行情库。相关性热力图留作后续。
3. **研究标注**：自定义股票池每只股票可填"所属板块/主题"和"研究理由"；股票池页、股票详情页显示，股票池分析可按板块分组。内容由用户填写，系统不代填。
4. **每日指标**：接入 tushare daily_basic（每个交易日一次调用，2010 年起约 4,060 次），存入本地行情库；估值组因子有真实数据；新增换手率、市值类因子；UBL 补上市值中性化。财务报表不接，基本面组和盈利质量组继续不可用。
5. **港股**：继续搁置，文档写明"已调研，未接入"。
6. **内置模型策略可复现**：训练设置写进内置策略定义；启动时模型缺失就自动排队训练，完成后自动算成绩卡。训练出的模型仍不进仓库。
7. **LSTM**：第二批算法只做 LSTM（过去 60 天的因子序列，滚动规则不变），建一个内置模型策略；Transformer 暂不做。
8. **清理验收模型**：删除 ADR-0052 对比用的 4 个验收模型（结果已记录），删除前向用户列出确认。
9. **演示与文档**：更新 README 与截图，写一页演示脚本。

## 后果

- 需要一次约 4,060 次调用的数据补齐，此后每天 1 次。
- 估值组从"不可用"变为可用，已有用到估值组的策略成绩卡需要重算。

## 结果（2026-09-24）

- **数据说明**：策略详情和回测报告顶部显示；由后端按策略规格和回测区间统一生成（`/strategies/{id}/data-note`）。
- **股票池分析与研究标注**：已上线。研究标注存在自定义股票池上。数据库里原有 74 条 `research_annotations`（全部标"大盘核心"），来自最初 MVP 代码里写死的种子文字，不是本组按作业整理的标注，没有自动展示；是否导入由用户决定。
- **每日指标**：daily_basic 从 2010-01-04 补到 2026-09-23，共 4,063 个交易日，没有失败或空天；此后每天随日线一起补。估值组在真实模式下改用因子库里的真实市盈率、市净率、市销率和股息率。新增三个因子：20 日换手率、流通市值（对数）、市值中性 UBL。原 `ubl` 定义不变，因为已训练的模型用它作输入，改了会让训练和打分口径不一致。
- **内置模型策略可复现**：训练设置写进内置策略定义，模型编号由设置决定；启动时模型缺失（或上次失败）就排队训练，完成后自动算成绩卡。
- **LSTM**：每只股票过去 20 天的因子序列，每天换成百分位；标签是池内排名；每 5 天取一次训练样本；GPU 训练，沪深300 全量约 5 分钟。
  - **排名口径**：训练面板里停牌日价格会沿用前收（因为知道它后来复牌），打分面板最后一天停牌的股票却是空值，两边的排名口径因此不一致。已改为两边都排除停牌日，测试逐只核对训练时和打分时的预测一致（相对误差 1e-4）。
  - **成绩卡**：年化 11.6%，最大回撤 −18.5%，夏普 0.83，样本外平均 IC 0.110。与树模型的差别不只是网络结构：标签（池内排名）和输入（百分位序列）也不同，没有做消融；它又是二十多个策略里夏普第二的一个，有挑选的运气成分。
- **新内置策略成绩卡**：估值因子选股年化 8.8%、回撤 −22.7%、夏普 0.56；市值中性 UBL 年化 8.0%，与原 UBL（8.2%）相当。
- **文档**：README 重写，删掉了基于今天名单、有幸存者偏差的旧收益数字；`docs/使用说明.md` 改写为演示脚本；截图更新到 `docs/screenshots/v2/`。
- **清理验收模型**：用户确认后，删除了 ADR-0052 对比用的 4 个验收模型（2016 年起数据；今天名单和历史成分股各 LightGBM、XGBoost 一个），删除前核对过没有策略引用。
- **每日指标不随仓库分发**（用户决定）：实际约 497MB，超出 GitHub 免费 LFS 额度的承受范围。已加入 `.gitignore`，并从尚未推送的提交里移除；新环境第一次启动时从 tushare 补齐（约 4,000 次调用）。
- **旧的 74 条种子标注**：不导入、不展示；研究标注由小组自己在股票池页填写。

## 收尾决定（2026-09-24）

- 不做：运行中每日自动补行情、"本组自己的策略"（策略库更重要）、"粉红股"、推送、全新环境验证、模型年度自动重训。
- 模拟盘清零，绑定"集成模型 + 单向波动差择时"（带择时，能演示每天调整仓位），打开每月自动调仓。绑定当天择时看空，目标仓位 0%，账户全现金；下个定期调仓日 2026-10-24。
- 已知限制：服务一直开着时行情不会自动更新，需要在"数据与模型"页点"补齐"或重启服务，择时和自动调仓才会用到新数据；2027 年起内置模型需要重训才能继续打分。
