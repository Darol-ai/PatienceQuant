# 截面标准化在30支候选池上重测——依然是负结果

## 动机

ADR-0008/0012 在10-12支股票的小候选池上测过截面标准化(把特征换成
同一天在股票池内的百分位排名)，结论是"样本太小、排名把连续特征压成
太少的离散档位，信息损失大于跨期稳定性的好处"。现在候选池已经扩大到
30支，分辨率理论上足够（30个离散档位而不是10-12个），值得重新验证
这个此前被否定的方向是否在更大规模下成立。

## 结果：规模扩大后依然是负结果

固定最终配置的其余部分（30支候选池+horizon=90+5模型集成+top_k_ratio
=0.4+动量兜底），只把原始特征换成截面百分位排名（新增预测时一致的
`CSRankEnsembleWalkForwardSignalSource`，仿照 V3 时期 `model_signal.py`
的"先算全部股票当天特征、再一起排名"逻辑，避免训练/预测口径不一致）：

| | 原始特征(ADR-0028/0030最终基线) | 截面标准化 |
|---|---|---|
| 跑赢年数 | 6/7 | 5/7 |
| 7年复合收益 | +428.0% | +285.1%（明显更差） |
| 2019超额 | -11.4% | **-21.9%（更差）** |
| 2021超额 | +3.9% | **-9.6%（转负）** |

**规模扩大到30支没有改变结论**——截面标准化依然是净负，2019不但没
改善反而恶化了一倍，2021也转负。这进一步确认 ADR-0008 的原始判断
不是"样本量不够"这么简单：至少在30支这个规模下，把连续特征压缩成
组内排名仍然丢失了比它带来的跨期稳定性更多的信息。

## 结论

不采用截面标准化。这是十五轮独立测试里的第十二个负结果/证伪案例。
**最终配置维持不变**：30支候选池+扩展历史+horizon=90(5模型集成)+
top_k_ratio=0.4+动量兜底(count=2,boost=1.5)+等权重，原始(非截面标准化)
特征。6/7年跑赢基准，7年复合收益+428.0%（真实基准+303.9%）。
