# 前端改版：以智能体为首页，按"策略库 → 实践 → 模拟盘"组织

## 背景

前端沿用 PatienceQuant 脚手架的结构（Dashboard / 股票池 / 策略 / 回测 / 模拟盘 / 自动交易 / AI 投研），ADR-0047～0050 之后已和实际流程脱节：智能体推荐埋在 AI 投研页的一张卡片里；成绩卡、模型库、本地行情库没有页面；同一个模拟账户拆在两页；Dashboard、股票池页的内容还停留在迁移前。本项目定位是课程演示（ADR-0047）。

## 决定

1. **导航**：首页（智能体）、策略库、策略实践、模拟盘、股票池、数据与模型、AI 工具。取消 Dashboard，它原有的净值、持仓、最近交易并入模拟盘。视觉沿用现有浅色主题，只调整结构。

2. **首页**以[智能体]对话为主体，右侧窄栏放成绩卡前三的策略、模拟盘当前策略和累计收益、行情库截至日期。演示时第一屏就能开始对话。

3. **智能体是引导式对话**：依次问市场、能接受的最大回撤、持仓周期（都有快捷按钮），问齐后按 ADR-0050 的规则推荐单个策略。之后支持四类追问：改偏好重新推荐、"为什么不是某个策略"（拿两张成绩卡对照、说明它在哪条规则上落选）、比较两个策略、解释名词。大模型只负责把用户输入的话翻译成这四类意图之一和对应参数，回答由规则和成绩卡生成，解释里的数字照样经过核对；没有配置大模型时只能点按钮。智能体不生成策略、不下单。对话只保留在当前浏览器，每次推荐照旧写审计记录。
   没选"完全由大模型主导的自由对话"，是因为推荐结果必须可复现、数字必须可核对。

4. **策略库是"策略"的唯一入口**：成绩卡对比表（可排序、可筛选）→ 策略详情（规格、成绩卡、逐年收益、全部回测历史，按钮"回测它 / 放进模拟盘 / 基于它新建"）。策略制定是从这里进入的编辑器，不单独占一个导航项。

5. **回测报告独立成页**，每次回测都有固定地址，策略库、智能体、策略实践都链接到它。策略实践页只放回测表单，跑完跳到报告页。

6. **模拟盘合并原"模拟盘"和"自动交易"**：绑定的策略、净值与持仓、手动调仓、自动调仓开关、交易账本。

7. **股票池页改成股票池管理**：固定股票池（沪深300 成分股、30 支候选池）和自定义股票池，外加 30 支候选池的研究标注。个股详情保留，只从持仓、回测买卖点、推荐结果进入。删除"大盘股核心池"等"按代码顺序取前 N 支"的代理股票池，避免被误当成真实指数成分股。

8. **数据与模型页**：本地行情库状态与补齐；模型库列表（类型、训练股票池、可以打分的年份、旧模型还是新训练的）。

9. **AI 工具**只保留研报总结；交易解释改挂在回测报告和模拟盘的具体交易上。删除"研报生成因子"：本项目不做文字策略，而它还依赖一条和流水线平行的旧回测路径。

10. **多因子 V3 的默认股票池改为真实沪深300 成分股**，并重算成绩卡。这是看过结果之后才做的改动：原默认池是通用目录按代码顺序的前 300 支（成绩卡年化 3.9%、最大回撤 −61.3%），而策略本身叫"沪深300 增强"；在真实成分股上是年化 19.9%。改动理由是原股票池名不副实，不是为了提高成绩。

## 后果

- 旧的 Dashboard、自动交易页、策略参数助手、研报生成因子相关代码删除。
- 自定义股票池（watchlist）从回测表单里的临时手选，变成在股票池页管理、回测时下拉选择。
