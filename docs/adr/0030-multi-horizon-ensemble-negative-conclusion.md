# 跨预测窗口集成——同样是净负结果，正式收尾2019专项攻坚

## 假设

不同于ADR-0028/0029"同一horizon(90天)多个随机种子"这种噪声降噪，这里
换一种模型多样性来源：训练目标本身不同——分别对horizon=60/90/120天各
训一组5种子集成，再把三组的预测取平均。假设不同horizon关注的趋势
尺度不同，能互相抵消单一horizon(90天)对2019这类特定行情的偏差。

## 结果：又一次净负

新增 `app/quant_v3/multi_horizon_signal.py::MultiHorizonSignalSource`。
固定其余配置（ADR-0028最佳版本），只把信号源从"h90单一5种子集成"换成
"h60+h90+h120三组集成再平均"：

| | h90单一集成(ADR-0028基线) | h60+h90+h120三窗口集成 |
|---|---|---|
| 跑赢年数 | 6/7 | 6/7（持平） |
| 7年复合收益 | +428.0% | +360.9%（更差） |
| 2019超额 | -11.4% | **-10.2%（略有改善）** |
| 2020超额 | +13.8% | **+2.6%（大幅下降）** |

2019又小幅改善了一点，但2020的正超额被大幅削弱，总收益从428.0%降到
360.9%。**这是第四次"救2019、伤别处"的净负模式**（前三次是ADR-0023
拉长窗口、ADR-0024持仓粘性、ADR-0029扩大种子数）。测试172/172全绿
（新增信号源类，未加单测，同已有信号源先例）。

## 2019专项攻坚：十轮尝试的最终总结

| 轮次 | 方向 | 结果 |
|---|---|---|
| ADR-0016 | 训练历史扩展(冷启动假设) | 证伪 |
| ADR-0022 | 动量兜底 | **净正**（0/7年问题的破局点） |
| ADR-0023 | 拉长动量窗口 | 净负 |
| ADR-0024 | 持仓粘性 | 净负 |
| ADR-0025 | 动量兜底权重倍数 | **净正** |
| ADR-0026 | 熊市校准窗口假设 | 证伪 |
| ADR-0027 | 加深模型容量 | 证伪 |
| ADR-0028 | 同horizon多种子集成 | **净正**（撞上真实bug后修复） |
| ADR-0029 | 扩大集成种子数(10个) | 净负 |
| ADR-0030(本篇) | 跨horizon集成 | 净负 |

十轮里三轮（动量兜底、权重倍数、同horizon集成）带来真实、无代价的
净正改善，把2019的差距从最初的-21.7%（ADR-0021）收窄到-11.4%
（ADR-0028，目前维持的最佳值）。其余七轮均是净负或被数据证伪的假设。

## 结论：正式收尾，维持 ADR-0028 配置

不再继续搜索"专门解决2019"的新机制——七次负结果里有四次呈现同一种
模式（改善2019、损害其它年份），这是一个足够强的信号：2019 在当前
"30支候选池、纯技术特征、月度调仓"这套方法论下，是一个结构性难以
单独攻克的年份，不是还没找到对的参数组合。继续搜索的边际成本
（每一轮都要重新训练模型、写脚本、交叉验证）已经明显超过边际收益
（过去三轮"净负"尝试对2019的改善都在1-2个百分点以内，同时以更大的
其他年份损失为代价）。

**最终配置（不再变动）**：30支候选池 + 扩展历史(2010起) + horizon=90 +
top_k_ratio=0.4 + 5模型集成(subsample/colsample=0.8) + 动量兜底
(count=2, boost=1.5) + 等权重 + 无趋势过滤。

**最终成绩**：6/7年跑赢基准，7年复合收益+428.0%（基准+303.9%），
唯一未解决年份2019超额收益-11.4%。这是本轮自由探索（`/goal` 阶段，
ADR-0013起）的最终交付结果。

## 收尾前的最后一次验证：排除2019两支极端黑马，问题不但没解决反而更差

为了确认2019的问题到底是"没接住这两支特定黑马"还是"更广泛的行情特征"，
做了最后一次对照：把立讯精密(002475.SZ)、牧原股份(002714.SZ)——2019年
涨幅最猛的两支——直接从候选池剔除（不重新训练模型，只是不让策略/基准
交易这两支），用剩下28支重跑2019：

| | 含这两支黑马(30支,基线) | 排除这两支(28支) |
|---|---|---|
| 策略收益 | +52.1% | +36.4% |
| 基准收益 | +63.5% | +52.2% |
| 超额收益 | -11.4% | **-15.9%（更差）** |

**排除黑马后差距反而扩大，不是缩小**——说明这两支个股不是2019问题的
根本原因，即使把它们完全拿掉，只要行情本身是"28/30支普涨"这种近乎
全员上涨的结构，选择性策略依然会因为"不是满仓覆盖全部"而系统性跑输
满仓买入持有的基准。这最终确认了本轮系列诊断反复出现的结构性判断：
2019 的问题是"近乎普涨的市场行情"本身，不是"选错了或漏掉了哪几支
股票"，为"正式收尾这条2019专项攻坚线"这个决定提供了最后一份直接证据。

## 联合复核：确认 top_k_ratio=0.4 在完整最终机制下依然是最优

`top_k_ratio=0.4` 最初是在 ADR-0021 选定的，当时动量兜底(ADR-0022)、
权重倍数(ADR-0025)、模型集成(ADR-0028)都还没叠加上去——为排除"最优值
已经漂移"的可能，用完整的最终机制（5模型集成+动量兜底count=2,
boost=1.5）重新网格测了 {0.3, 0.35, 0.4, 0.45, 0.5}：

| top_k_ratio | 跑赢年数 | 7年复合收益 |
|---|---|---|
| 0.3 | 6/7 | +378.4% |
| 0.35 | 6/7 | +425.3% |
| **0.4** | **6/7** | **+428.0%（最高）** |
| 0.45 | 6/7 | +361.8% |
| 0.5 | 6/7 | +372.3% |

0.4 两侧（0.35和0.45）都更差，确认这是叠加全部机制后依然成立的真实
局部峰值，不是早期不完整流程下的偶然选择。**最终配置到此确认完毕，
不再变动。**
